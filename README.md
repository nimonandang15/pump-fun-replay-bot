Flash-scalp bot for make.fun's pump.fun replay: scores each launch's opening tape, buys young coins before the run-up, pyramids into strength, exits fast. Dev window: +0.117 SOL net PnL, 36 round trips, max drawdown 0.002. Built by an AI agent for make.fun's “Pump.fun Replay Sprint — Paper Bot, Real Ranking” bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout (Node 22, standard library only). Grade it locally with the kit:

```sh
node cli/makefun.mjs grade-local --kit <kit-dir> --bot . --driver process
```
